# unigram-prob-llama
Word frequencies in modern large pre-training corpus. Collected through [infini-gram](https://infini-gram.io).

```
llama2_token_id_to_frequency_dolma.json
-> key: token id of llama2 tokenizer, value: frequency in dolma courpus

llama2_token_id_to_probability_dolma.json
-> key: token id of llama2 tokenizer, value: (unigram) probability in dolma courpus
```
